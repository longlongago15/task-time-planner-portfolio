# 安全性・依存関係・素材

このアプリはローカル利用向けです。正式認証・Owner認可は未実装であり、APIをそのままインターネットへ公開しません。

## データと秘密情報

通常の起動入口は自分の `.local-data` 以下のSQLiteだけを選択します。継承されたDATABASE_URLやMySQL指定を拒否し、SQLAlchemyの接続ガードでも接続先を照合します。初期化は新規ファイルの排他的作成で既存DBの上書きを拒否します。

`.env`・DB・バックアップ・秘密鍵・資格情報・ブラウザプロファイル・内部ログはGit対象外です。画面撮影には架空のサンプルデータを使います。個人の実データ・端末の実パス・接続識別子は公開資料へ含めません。

## 依存関係

基準版の監査で見つかった既知の脆弱性に対し、提出用コピーだけで以下を変更しました。業務仕様は変更していません。

- FastAPI 0.115.0 → 0.135.0：修正版Starletteと互換の構成へ更新。
- Starlette 1.3.1を明示固定：[開発元の修正情報](https://github.com/Kludex/starlette/security/advisories/GHSA-82w8-qh3p-5jfq)。
- pytest 8.3.3 → 9.0.3：[pytestのリリース情報](https://docs.pytest.org/en/stable/announce/release-9.0.3.html)。
- source-map-js 1.2.1 → 1.2.2：Frontendの間接依存だけを更新。[修正版](https://github.com/7rulnik/source-map-js/releases/tag/v1.2.2)。
- 隔離仮想環境のpipも26.2.1へ更新。

照合日：2026-10-20。ロックファイルから新規導入した27依存とpipを含むPython環境28パッケージを公式PyPIの脆弱性情報で照合し、検出0でした。npmのlockfileは70依存エントリを公式監査へ照合し、検出0でした。実行結果と対象版はこの提出用ツリーに対応しています。

PyMySQLは接続設定の安全性をモック検証する開発依存として残しています。実MySQLへの接続や専用Migrationは行わず、runtime依存には含めていません。未使用のAlembicは公開依存から除外しました。

公開ファイルの文字列スキャンでは、固定テスト用ダミー値と日付パーサーの正規表現を区別して確認しました。実資格情報・個人の端末パスを検出したという結果ではありません。

アドバイザリ照合で検出0という結果は、すべての未知の脆弱性や業務上の問題の不存在を保証しません。照合日・実行環境を検証記録と区別せずに扱わないでください。

この照合の対象はPyPI / npmの依存です。OS、Pythonに同梱されたSQLite、ブラウザ本体の脆弱性評価は含めていません。
